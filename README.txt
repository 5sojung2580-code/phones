Virtual Phone Studio v2 — 홈 화면 자유 편집

기존 GitHub phones 저장소의 루트에 index.html, admin 폴더, p 폴더를 그대로 업로드하여 덮어쓰세요.
관리자: /phones/admin/ → 캐릭터 선택 → 홈 화면 꾸미기 → 저장 및 반영
플레이어: 기존 캐릭터별 /phones/p/?id=... 주소 유지
기존 Firestore 문서와 보안 규칙은 변경하지 않습니다.
위젯은 시각적 카드이며 실시간 날씨 데이터는 제공하지 않습니다.
앱 아이콘은 기존 메시지/갤러리/전화/설정으로 연결합니다.
공개 캐릭터의 Firestore 데이터는 공개 읽기가 가능합니다.
